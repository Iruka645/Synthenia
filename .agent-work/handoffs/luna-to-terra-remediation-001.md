## Implementation decisions by finding

### AUD-001

- `VisionCoordinator` now owns one identity-based active flight with `RUNNING`
  and `DRAINING` states.
- Timeout/external abort rejects promptly with typed `VISION_TIMEOUT` or
  `VISION_ABORTED`, aborts the provider signal, logs one sanitized metadata-only
  outcome, and retains the admission lock/frame until the exact provider
  promise settles.
- New requests remain `VISION_BUSY` during drain. Late fulfillment/rejection is
  consumed without normalize/store/log/public side effects and releases once.
- Normal completion rechecks identity/abort state before normalization and
  storage, retaining ownership through store, log, and public completion.
- Provider-shaped validation errors are sanitized unless generated by local
  normalization.

### AUD-002

- PNG requires signature, first/unique valid `IHDR`, supported depth/color pair,
  all-chunk CRC-32, `IDAT`, zero-length terminal `IEND`, and no trailing data;
  unknown critical chunks fail closed.
- JPEG walks bounded marker segments, validates supported single-frame SOF and
  SOS structures, handles stuffed/restart/scan markers, and requires terminal
  EOI with no trailing data. Truncation, duplicate frame, and illegal
  standalone markers fail closed.
- WebP requires exact RIFF size, bounded chunks, zero odd padding, one valid
  still `VP8 ` or `VP8L` primary, optional preceding valid `VP8X`, matching
  dimensions, and no animation chunks/flags.
- Parsing is forward, bounded, dependency-free, non-decompressing, and does
  not copy Uint8Array input.
- Fixture hashes (decoded bytes): PNG
  `431ced6916a2a21a156e38701afe55bbd7f88969fbbfc56d7fe099d47f265460`; JPEG
  `9dacf9b93ef343cb1b10d45dcd84959c4448a68d0859d818cc3decfb7dbf619f`; WebP
  `52dc24c0429ea6ccc5b579a6da8bb79bf41e471fe5108a62009f3c2e195551c0`.

### AUD-003

- `AdaptiveCaptureController` now uses monotonically increasing session/run
  generations and identity-owned stream/controller/frame resources.
- It checks generation, signal, and session validity after capture, after
  analysis, and before success/rescheduling.
- Hidden, ended, disconnected, stream-error, stop, and analyzer-error paths
  invalidate the generation, abort once, release owned frame/stream once, emit
  a sanitized terminal state, and never reschedule.
- Late frames/completions from an invalidated run cannot mutate a newer session
  or release its resources. Manual/periodic/start/timer work has one shared
  unsettled slot and never queues a second operation.

### AUD-004

- Capture age/future skew remains admission-only: maximum age 300,000 ms and
  future skew 30,000 ms.
- Completion revalidates schema/timestamps without capture-age rejection;
  observation validation enforces captured/observed skew, observed-clock skew,
  exact 120,000 ms TTL, unexpired state, and analysis timing <=480,000 ms.
- One completion clock value feeds elapsed time, observedAt, TTL validation, and
  completion logging. Six-minute admitted work succeeds with a completion-
  relative TTL; elapsed >=480,000 ms returns timeout without storage.
